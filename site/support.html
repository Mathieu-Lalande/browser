Assistance

Besoin d'aide ?

Réponses aux questions fréquentes sur Browser pour ordinateur, iPhone, iPad et Android, et comment nous joindre. English version below.

Nous contacter

  • Signaler un problème ou proposer une idée : tickets GitHub (indiquez l'appareil, le système et la version de Browser, visible dans Paramètres, À propos).

  • Confidentialité : voir la politique de confidentialité.

Questions fréquentes

Comment synchroniser l'ordinateur et le téléphone ?

Activez la synchronisation sur l'ordinateur (Paramètres, Synchronisation) avec votre serveur, affichez le code de jumelage, puis scannez-le depuis le téléphone (Paramètres, Synchronisation). Détails dans le guide.

Comment faire de Browser le navigateur par défaut ?

Android : Paramètres du téléphone, Applications, Applications par défaut, Navigateur, puis Browser. iPhone et iPad : Réglages, Apps, Browser, App de navigation par défaut (quand la version installée le permet). Ordinateur : Paramètres de Browser, Navigateur principal.

Mes données sont-elles envoyées quelque part ?

Non, sauf si vous activez la synchronisation (chiffrée de bout en bout, vers votre serveur), l'assistant IA ou la traduction (avec votre clé). Voir la politique de confidentialité.

J'ai perdu le code de jumelage ou un appareil

Personne ne peut retrouver la clé : les données sont chiffrées avec elle. Dans Paramètres, Synchronisation, choisissez « Réinitialiser » sur un appareil qui a encore les données, puis jumelez à nouveau les autres.

Support (English)

  • Report a problem or suggest an idea: GitHub issues (include your device, OS and Browser version, shown in Settings, About).
  • The user guide (in French) covers every feature step by step.
  • Sync: turn it on on the computer with your server, show the pairing code, then scan it from the phone (Settings, Sync).
  • Default browser: Android, phone Settings, Apps, Default apps, Browser app; iPhone and iPad, Settings, Apps, Browser, Default Browser App (when the installed version allows it).
  • Privacy: nothing is sent anywhere unless you turn on sync (end-to-end encrypted, to your server), the AI assistant or translation (with your key). See the privacy policy.
