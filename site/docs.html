Installation

Téléchargez la dernière version depuis la page de téléchargement : le bouton principal détecte votre système. Tous les fichiers sont aussi dans les versions publiées sur GitHub, avec SHA256SUMS.txt pour les vérifier.

Windows 10 et 11

  1. Téléchargez Browser-Setup-<version>-x64.exe (ou -arm64.exe pour Windows sur ARM).
  2. Lancez-le. Choisissez une installation pour vous seul (sans droits administrateur, par défaut) ou pour tous les utilisateurs.
  3. Si SmartScreen affiche « Windows a protégé votre ordinateur » : « Informations complémentaires » puis « Exécuter quand même » (les paquets ne sont pas encore signés).

L'installateur crée un raccourci dans le menu Démarrer, propose un raccourci sur le Bureau et se désinstalle depuis Paramètres, Applications ; votre profil est conservé. La version portable Browser-<version>-win-x64.zip se lance sans installation mais ne se met pas à jour seule.

macOS 12 ou plus récent

  1. Téléchargez Browser-<version>-mac-arm64.dmg (Apple Silicon) ou -mac-x64.dmg (Intel).
  2. Ouvrez le .dmg et glissez Browser dans Applications.
  3. Au premier lancement, faites un clic droit sur Browser puis « Ouvrir » (l'app n'est pas encore notarisée), ou autorisez-la dans Réglages Système, Confidentialité et sécurité.

Linux 64 bits

  • AppImage : rendez le fichier exécutable (chmod +x Browser-*.AppImage) puis lancez-le. Il se met à jour tout seul.
  • Paquet .deb (Debian, Ubuntu) : sudo apt install ./Browser-*.deb. Mise à jour manuelle.

Vérifier un fichier

Comparez l'empreinte du fichier téléchargé avec celle de SHA256SUMS.txt : sha256sum <fichier> (Linux), shasum -a 256 <fichier> (macOS) ou Get-FileHash <fichier> (PowerShell).

Pour compiler Browser vous-même (Node.js 22, npm install puis npm run dev), suivez docs/INSTALL.md.

Application mobile

L'application iPhone et Android n'est pas encore sur les stores. Deux façons de l'utiliser dès maintenant :

Avec Expo Go (le plus simple)

  1. Installez Expo Go (App Store ou Play Store), version à jour (SDK 58).
  2. Sur un ordinateur avec Node.js : clonez le dépôt, puis cd mobile, npm install et npx expo start.
  3. Scannez le QR code (appareil photo sur iPhone, Expo Go sur Android). Même Wi-Fi requis, sinon npx expo start --tunnel.

En version compilée (TestFlight, APK)

Avec EAS Build, le service de compilation d'Expo (pas besoin de Mac) : eas build --platform ios puis eas submit pour TestFlight (compte Apple Developer requis), ou eas build --platform android --profile preview pour un .apk à installer directement. Le détail est dans docs/INSTALL.md.

Ce que fait l'application

  • Barre d'adresse en bas, repliée au défilement ; balayez-la pour changer d'onglet.
  • Recherche plein écran (même moteur que la barre universelle du bureau), vue des onglets en grille par espace, dossiers, favoris et archivage.
  • Navigation privée, HTTPS uniquement, mode lecture, version ordinateur d'un site, aperçu des liens par appui long.
  • Mots de passe dans le trousseau du téléphone, boosts (sans l'outil de masquage), thèmes partageables.
  • Mini-lecteur au-dessus de la barre d'outils quand la page joue un média.
  • Synchronisation chiffrée avec le bureau (jumelage par QR code).

Le bloqueur de pubs mobile arrivera avec la version compilée (phase 2).

Premiers pas

La fenêtre de Browser se compose de trois zones :

  • La barre latérale (à gauche, ou à droite dans Paramètres, Disposition) : barre d'adresse, grille des favoris, onglets épinglés, dossiers et onglets de l'espace courant, et en bas les espaces. Masquez-la avec Ctrl S (⌘ S).
  • La page, avec une petite marge réglable autour, ou bord à bord.
  • La barre universelle qui flotte au-dessus de la page quand vous tapez Ctrl K (⌘ K).

Tapez une adresse ou une recherche dans la barre d'adresse (Ctrl L) : la recherche passe par DuckDuckGo par défaut (Paramètres, Recherche pour en changer). Les boutons de la barre (copier le lien, zoom, favori, protections, options de la page) apparaissent au survol ; le cadenas, lui, reste visible et ouvre les infos sur le site.

La page d'accueil affiche une salutation, l'horloge et vos sites les plus visités ; tout se règle dans Paramètres, Page d'accueil. Les paramètres (Ctrl ,) s'appliquent à chaud et se retrouvent aussi en tapant leur nom dans la barre universelle.

Au démarrage, Browser restaure votre session : les onglets reviennent, chargés seulement quand vous les ouvrez.

Navigateur principal, historique, import

Navigateur par défaut

Au premier lancement, la page d'accueil propose une fois de faire de Browser votre navigateur par défaut (« Plus tard » la fait disparaître). Le réglage se retrouve dans Paramètres, Comportement, Navigateur par défaut. Sous Windows 10 et 11, le bouton ouvre les Paramètres de Windows sur la page de Browser : choisissez-le pour les liens web et, si vous le souhaitez, pour les fichiers HTML et PDF. Sous macOS, le système vous demande confirmation ; sous Linux, Browser devient le gestionnaire des liens http et https.

Un lien cliqué dans une autre application, ou un fichier HTML ou PDF ouvert depuis l'explorateur, s'ouvre dans un nouvel onglet de la dernière fenêtre normale utilisée (jamais dans une fenêtre privée).

Lecteur PDF

Les PDF s'affichent directement dans l'onglet, en ligne comme sur votre disque, avec le lecteur intégré de Chromium (zoom, recherche, impression, téléchargement). Un PDF envoyé comme pièce jointe par le site est téléchargé, comme avant.

Historique

Ctrl H (⌘ Y), le menu « … », Historique, Tout l'historique, ou @h dans la barre universelle ouvrent browser://history : les pages visitées jour par jour, une recherche, la suppression d'une page ou d'une sélection, et Effacer l'historique sur la dernière heure, aujourd'hui, les 7 derniers jours ou tout. Les fenêtres privées n'enregistrent ni n'affichent l'historique.

Importer depuis un autre navigateur

Paramètres, Données, Importer… (ou browser://import) détecte Chrome, Edge, Brave, Vivaldi, Opera, Chromium, Firefox et Arc et leurs profils. Choisissez ce qu'il faut reprendre : favoris (rangés dans des dossiers du même nom), historique, moteur de recherche, et pour Arc les favoris de la barre et les onglets épinglés de chaque espace. Rien n'est importé deux fois.

Les mots de passe des autres navigateurs sont chiffrés avec une clé du système que Browser ne doit pas lire : exportez-les en CSV depuis l'autre navigateur (Chrome, Edge : Gestionnaire de mots de passe, Exporter ; Firefox : Mots de passe, « … », Exporter), choisissez le fichier dans la page d'import, puis supprimez-le. Safari n'est pas importé.

Onglets

  • Ouvrir, fermer : Ctrl T, Ctrl W. Où s'ouvre un nouvel onglet et lequel s'affiche après une fermeture : Paramètres, Comportement.
  • Épingler : clic droit, « Épingler l'onglet », ou double-clic sur l'onglet. Un onglet épinglé reste en haut de la barre.
  • Dupliquer avec son historique : Ctrl Maj K.
  • Passer d'un onglet à l'autre : Ctrl Tab / Ctrl Maj Tab, ou Ctrl 1…9.
  • Aperçu au survol : laissez le pointeur sur un onglet, un favori ou une icône du rail compact : une carte montre la miniature de la page, son titre, le site, et si l'onglet joue du son ou est en veille. Passez d'un onglet à l'autre, la carte suit aussitôt. Désactivable dans Paramètres, Disposition, « Aperçu des onglets au survol ».
  • Au clavier : la liste des onglets est un seul arrêt de tabulation ; ↑ ↓, Début Fin pour se déplacer, Entrée pour afficher, Suppr pour fermer.
  • Menu de l'onglet (clic droit) : épingler, dupliquer, vue scindée, déplacer vers un espace ou un dossier, mettre en veille, couper le son, fermer.
  • Rouvrir l'onglet fermé : Ctrl Maj T (⇧ ⌘ T), plusieurs fois pour remonter (25 derniers, jamais écrits sur le disque).
  • Sélectionner plusieurs onglets : Ctrl + clic (⌘ + clic sur Mac), ou « Sélectionner tous les onglets ». Une barre d'actions apparaît : nouveau dossier, déplacer vers un espace, fermer, annuler (Échap).

Mise en veille

Un onglet inactif depuis le délai choisi (Paramètres, Comportement : jamais, 15 min, 30 min…) est mis en veille : sa mémoire est libérée et il se recharge quand vous y revenez. Jamais pour un onglet qui joue du son, attend une autorisation ou contient un formulaire en cours. Les commandes « Mettre l'onglet en veille » et « Mettre les autres onglets en veille » le font tout de suite.

Menus et gestes

Menu de l'application « … »

Le bouton « … » en tête de la rangée de navigation ouvre le menu complet : état de la synchronisation, nouvel onglet et fenêtres, rangée de zoom (− % +) et plein écran, historique récent, favoris, téléchargements, mots de passe, extensions et thèmes, imprimer, enregistrer la page, rechercher dans la page, plus d'outils (captures, vidéo, lecture, boost, code source…), paramètres, aide (raccourcis, à propos, signaler un problème) et quitter. Au clavier : flèches pour se déplacer, → ou Entrée pour ouvrir un sous-menu, ← ou Échap pour revenir.

Menus contextuels

  • Espace vide de la barre latérale (clic droit) : nouvel onglet, nouveau dossier, actualiser, favori, sélectionner tous les onglets, rouvrir l'onglet fermé, mode compact, changer le côté de la barre latérale, modifier l'espace.
  • Pastille d'espace (clic droit) : renommer, icône et couleur, déplacer à gauche ou à droite, supprimer (après confirmation).
  • Page (clic droit) : précédent, suivant, actualiser et favori en tête, puis « Enregistrer la page sous… » (HTML complet ou MHTML), « Tout sélectionner », « Capture d'écran », « Afficher le code source » (Ctrl U), « Envoyer à un appareil » et « Inspecter ». Sur un lien : nouvel onglet, arrière-plan, vue scindée, autre espace, fenêtre privée, aperçu, copier.

Mode compact

Commande « Mode compact » (menu de la barre latérale ou barre universelle) : la barre latérale devient un rail d'icônes qui se déplie au survol. Le mode zen reste prioritaire.

Gestes sur la page

  • Pincer sur le pavé tactile ou Ctrl + molette : zoom de la page, mémorisé par site comme Ctrl +.
  • Balayer à deux doigts horizontalement : page précédente ou suivante. Une flèche suit le geste ; il ne se déclenche que lorsque la page ne peut plus défiler dans ce sens.
  • Plein écran : F11 (⌃ ⌘ F). Imprimer : Ctrl P (⌘ P).

Espaces et gestes

Un espace regroupe des onglets autour d'un contexte (travail, études, loisirs), avec son nom, son icône et sa couleur d'accent. Créez-en un avec le bouton « Nouvel espace », à côté des pastilles d'espace en bas de la barre latérale, ou la commande du même nom.

  • Changer d'espace : clic sur son icône, Ctrl Alt ← / →, ou Ctrl Alt 1…9 (⌥ ⌘ sur Mac).
  • Balayage : glissez à deux doigts horizontalement sur le pavé tactile, le pointeur sur la barre latérale, ou d'un doigt sur un écran tactile. La liste suit le geste ; relâchez au-delà du quart pour changer d'espace.
  • Espace isolé : dans l'éditeur d'espace, cochez l'isolation pour lui donner ses propres cookies et connexions, comme un conteneur (deux comptes du même site côte à côte).
  • Déplacer un onglet : clic droit sur l'onglet, « Déplacer vers ».
  • Modifier, réordonner, supprimer un espace : clic droit sur sa pastille, ou commande « Modifier le thème de l'espace ».

Dans la page, un balayage à deux doigts (macOS) ou Alt ← / → navigue en arrière et en avant.

Vue scindée

Affichez deux à quatre onglets côte à côte : Ctrl Maj \ (⇧ ⌘ \) associe l'onglet actif au suivant, et le même raccourci quitte la vue. Depuis le menu d'un onglet, « Vue scindée » ; depuis la barre universelle, Maj Entrée ouvre un résultat à côté.

Faites glisser les séparateurs pour ajuster les volets ; la disposition est restaurée au démarrage.

Dossiers, favoris, archivage

Dossiers

Commande « Nouveau dossier » ou menu d'un onglet. Glissez-déposez les onglets dedans ; un dossier peut en contenir d'autres (4 niveaux), avoir une icône et se replier (l'onglet actif reste visible). Un lien ouvert depuis un onglet rangé reste dans le même dossier.

Favoris

  • Ctrl D ajoute ou retire la page des favoris (gérés dans Paramètres, Données).
  • « Ajouter aux favoris (tous les espaces) » place le site dans la grille des favoris, en haut de la barre latérale, commune à tous les espaces.

Archivage automatique

Les onglets que vous n'ouvrez plus sont archivés après le délai choisi (Paramètres, Comportement : jamais, 12 h, 24 h, 7 jours par défaut, 30 jours). Jamais l'onglet affiché, épinglé, de la grille des favoris, qui joue du son ou en vue scindée. Retrouvez-les avec la commande « Onglets archivés » (browser://archive) ou le filtre de la barre universelle.

Barre universelle

Ctrl K (⌘ K) ouvre une recherche floue sur les onglets de tous les espaces, la grille des favoris, les favoris, l'historique, les commandes (avec leur raccourci), les réglages, les onglets de vos autres appareils et les onglets archivés. Rien n'est envoyé au moteur de recherche pendant la frappe.

Réponses instantanées

Calculées sur votre ordinateur, affichées en tête ; Entrée copie le résultat.

  • Calculs : 12*7+3, (1,5+2)^2, 15%.
  • Conversions : 12 km en miles, 350 F en C, 2 To en Go (longueur, masse, température, volume, vitesse, données).
  • Heure d'une ville : heure à Tokyo ; bases : 0xff, 255 en binaire.

Aperçu des liens

Maj + clic sur un lien, ou clic droit puis « Aperçu du lien » : la page s'ouvre dans une carte flottante au-dessus de l'onglet. Gardez-la avec « Ouvrir dans un onglet » (sans rechargement) ou « Ouvrir en vue scindée », ou fermez-la avec Échap ou un clic à côté. Rien n'est ajouté à l'historique.

Sur le téléphone, un appui long sur un lien propose l'aperçu dans une feuille.

Mode lecture et version mobile

Sur un article, Ctrl Alt R (⌥ ⌘ R) ou Options de la page, « Mode lecture » : le texte et ses images seuls, dans une mise en page calme. Le même raccourci revient à la page.

« Demander la version mobile » (Options de la page) recharge le site comme le verrait un téléphone ; sur l'application mobile, l'inverse : « version ordinateur ».

Traduction

Désactivée par défaut : pour traduire, le texte de la page est envoyé à un service en ligne. Choisissez-le dans Paramètres, « Traduction » : DeepL (clé d'API Free ou Pro), LibreTranslate (votre serveur ou un serveur public, clé facultative) ou Google Cloud Translation (clé d'API). « Tester » vérifie la configuration. Les clés sont chiffrées par le système (trousseau) et ne sont jamais réaffichées.

Sur une page dans une autre langue, l'icône de traduction apparaît dans la barre d'adresse : choisissez les langues (« Détecter » laisse le service reconnaître la langue), puis « Traduire ». La première fois, le navigateur rappelle que le texte part vers le service choisi. Aussi : Ctrl Alt T (⌥ ⌘ T), le menu « … » ou le clic droit sur la page.

  • La partie visible est traduite d'abord, puis le reste et le contenu qui arrive ensuite ; le code, les scripts, les champs de formulaire et les zones modifiables ne sont jamais envoyés.
  • « Afficher l'original » remet le texte exact de la page, sans la recharger.
  • « Toujours traduire cette langue » et « Jamais pour ce site » se retrouvent et se retirent dans les paramètres.
  • Fenêtres privées : confirmation demandée à chaque fenêtre, règles gardées en mémoire seulement.
  • Sur le téléphone : menu de la page, « Traduire la page » puis « Afficher l'original » ; le service et sa clé se règlent dans Paramètres, « Traduction ».

Assistant IA

Facultatif et désactivé par défaut. L'assistant utilise Claude d'Anthropic avec votre propre clé d'API (à créer sur console.anthropic.com, facturée sur votre compte) : Paramètres, « Assistant IA », activez-le, collez la clé, puis « Tester ». Modèle par défaut : Claude Opus 5.5, rapide ; Claude Fable 5.1 est l'option « plus puissant ».

Ouvrez le panneau à côté de la page avec Ctrl Alt A (⌥ ⌘ A), le menu « … » ou le clic droit. Actions rapides : « Résumer la page », « Points clés », « Expliquer la sélection », « Traduire la sélection », ou une question sur la page. Sélectionnez plusieurs onglets (Ctrl+clic) puis l'icône de l'assistant pour les comparer. Dans la barre universelle, @ia suivi d'une question l'envoie, avec ou sans la page.

  • Chaque demande indique ce qui a été envoyé (titres des pages, « tronqué » pour une page trop longue).
  • Les réponses arrivent au fil de l'eau : « Arrêter » les interrompt ; « Copier » et « Ajouter aux notes » les gardent.
  • Les conversations restent en mémoire, par onglet ; elles s'effacent au changement de page sauf si « Garder les conversations » est activé.
  • Sur le téléphone : menu de la page, « Assistant IA » (résumé, points clés, question), mêmes réglages.

Notes et surlignages

Sélectionnez du texte dans une page, puis clic droit, « Surligner » et une couleur (jaune, vert, bleu ou rose), ou Ctrl Maj H (⇧ ⌘ H) avec la dernière couleur choisie. Le passage reste surligné à chaque visite, même si la page a un peu changé.

  • Un clic sur un passage surligné ouvre sa fiche : couleur, note, « Copier », « Supprimer ».
  • « Notes de la page » (Ctrl Alt N) ouvre un panneau à côté de la page : une note libre pour la page et la liste de ses passages ; un clic fait défiler la page jusqu'au passage.
  • browser://notes rassemble tout, groupé par site : recherche, filtre par couleur, export Markdown ou JSON, suppression. Dans la barre universelle, @n cherche dans vos passages et notes.
  • Synchronisation facultative (Paramètres, « Synchronisation », « Notes et surlignages »), chiffrée de bout en bout comme le reste.
  • Fenêtres privées : les notes restent en mémoire et disparaissent à la fermeture de la fenêtre.
  • Sur le téléphone : sélectionnez du texte puis « Surligner » ; touchez un passage pour changer sa couleur ou le supprimer ; la liste est dans Paramètres, « Notes et surlignages ».

Boosts

Un boost personnalise un site (ou un domaine et ses sous-domaines, *.exemple.fr) :

  • filtres de couleur (inversion, gris, sépia, luminosité, contraste) et police ;
  • éléments masqués : commande « Masquer des éléments », puis cliquez sur ce qui gêne (Échap pour terminer) ;
  • CSS personnalisé, et un script en option (désactivé par défaut, avec un avertissement).

Créez et modifiez vos boosts depuis Options de la page, « Boost du site », ou la page browser://boosts (commande « Boosts »). Ils sont synchronisés ; un script reçu d'un autre appareil reste désactivé tant que vous ne l'avez pas accepté.

Mots de passe

  • Enregistrer : après une connexion, Browser propose d'enregistrer l'identifiant (ou « Jamais pour ce site »).
  • Remplir : uniquement à votre demande, avec la clé qui apparaît dans la barre d'adresse sur un site connu, ou « Remplir le mot de passe » du menu de la page. Un mot de passe n'est proposé que sur le site exact où il a été enregistré.
  • Gérer : commande « Mots de passe » (browser://passwords) : recherche, affichage, modification, suppression, export CSV compatible Chrome et Firefox.

Les mots de passe sont chiffrés par le trousseau du système (Windows, macOS, Linux). Aucune invite en fenêtre privée. Ils ne sont pas synchronisés.

Adresses, cartes et clés d'accès

  • Enregistrer : après l'envoi d'un formulaire de livraison ou de paiement, Browser propose « Enregistrer cette adresse ? » ou « Enregistrer cette carte ? ». Les champs sont reconnus en français et en anglais (formats d'adresse France/Europe, Royaume-Uni, Amérique du Nord).
  • Remplir : en entrant dans un champ reconnu, une liste propose vos adresses ou cartes ; aussi « Remplir une adresse » du menu de la page (bureau et téléphone).
  • Gérer : Paramètres, « Adresses et paiements ». Afficher le numéro complet d'une carte demande Touch ID (Mac) ou une confirmation du système.

Tout est chiffré par le trousseau du système (téléphone : trousseau iOS / Keystore Android). Le code de sécurité (CVC) n'est jamais enregistré. Rien n'est proposé ni enregistré en navigation privée. Les adresses peuvent être synchronisées (désactivé par défaut, chiffré de bout en bout) ; les cartes ne quittent jamais l'appareil.

Clés d'accès (passkeys) et clés de sécurité

  • Windows : tout passe par Windows Hello (clés d'accès de ce PC, clés USB/NFC avec leur code PIN, connexion avec un téléphone par QR code).
  • macOS : les clés de sécurité USB sans code PIN fonctionnent. Touch ID et les clés d'accès iCloud ne sont pas disponibles dans les versions actuelles (il faut une version signée avec un droit de trousseau dédié) ; pas de connexion par téléphone.
  • Linux : clés de sécurité USB sans code PIN (l'utilisateur doit avoir accès au périphérique, règles udev) ; aucun authentificateur intégré.
  • Plusieurs comptes pour un site : Browser vous demande lequel utiliser.

Notifications et orthographe

  • Notifications : un site doit d'abord en demander l'autorisation (barre au-dessus de la page). Elles s'affichent avec le nom et l'icône du site ; un clic ramène l'onglet. Changer d'avis : Infos sur le site (Autoriser, Bloquer, Réinitialiser).
  • Ne pas déranger : Paramètres, Notifications.
  • Orthographe : Paramètres, Orthographe : langues des dictionnaires (Windows, Linux ; macOS suit les langues du système), mots ajoutés au dictionnaire ; suggestions et « Ajouter au dictionnaire » au clic droit.

Les notifications « push » reçues quand le site est fermé (service workers, Web Push) ne sont pas prises en charge par Electron : seuls les onglets ouverts peuvent en afficher.

Extensions

Commande « Extensions » (browser://extensions, aussi depuis Paramètres, Comportement) : ajoutez un dossier non empaqueté ou un fichier .zip / .crx. Activez, désactivez ou retirez-les depuis la même page.

Support partiel, celui d'Electron : scripts de contenu et une partie des API chrome.*, sans bouton d'action ni fenêtre surgissante d'extension, et jamais en fenêtre privée.

Options de la page, captures et vidéo

Le bouton Options de la page, au bout de la barre d'adresse (Ctrl Maj O), réunit : copier le lien, zoom (−, pourcentage pour revenir au défaut, +), captures, vidéo, mode lecture, version mobile, boost du site, infos sur le site et QR code de la page.

  • Zone visible : Ctrl Maj S (⇧ ⌘ S).
  • Page entière : Ctrl Alt S (⌥ ⌘ S), sans faire défiler la page.
  • Un élément : « Capture d'écran d'un élément », survolez puis cliquez (Échap annule).

Un aperçu s'affiche en bas à droite : « Copier » ou « Enregistrer » (PNG, dans le dossier des téléchargements).

Vidéo de l'onglet : Ctrl Alt V (⌥ ⌘ V) démarre et arrête l'enregistrement (image et son de l'onglet seulement). Un point rouge et un minuteur restent visibles dans la barre d'adresse ; à l'arrêt, le fichier WebM vous est proposé.

Téléchargements, recherche, zoom, médias

  • Téléchargements : enregistrés sans boîte de dialogue (ou toujours demander où, Paramètres, Téléchargements), avec pause, reprise et annulation. Les programmes et scripts attendent votre confirmation ; rien n'est ouvert automatiquement. Liste : Ctrl Maj J (⌥ ⌘ L) ou browser://downloads.
  • Rechercher dans la page : Ctrl F, puis Entrée / Maj Entrée, F3 ou Ctrl G pour l'occurrence suivante. Le compteur et la casse sont gardés par onglet.
  • Zoom : Ctrl + / - / 0, pincement ou Ctrl + molette, mémorisé par site ; zoom par défaut dans Paramètres, Apparence.
  • Médias : Ctrl M coupe le son de l'onglet ; « Image dans l'image » détache la vidéo ; Ctrl Alt P (⌥ ⌘ P) met tout en pause.

Pause des médias

Quand un autre onglet que celui affiché joue de la musique ou une vidéo, un mini-lecteur apparaît en bas de la barre latérale : pochette, titre et artiste annoncés par le site, barre de progression cliquable, lecture/pause, « Avancer de 10 s », image dans l'image pour une vidéo, et fermer (met en pause et masque le lecteur). Un clic sur le titre affiche l'onglet, même dans un autre espace. Une source mise en pause reste proposée 5 minutes.

  • Plusieurs sources : un compteur ouvre la liste de toutes, chacune avec lecture/pause, son et fermeture.
  • « Tout mettre en pause » (palette, menu ou raccourci) arrête tous les onglets de toutes les fenêtres.
  • Touches multimédias du clavier : elles pilotent le dernier lecteur actif.
  • Mode compact : un bouton lecture/pause dans le rail. Fonctionne aussi en fenêtre privée, sans rien enregistrer.
  • Téléphone : une barre au-dessus de la barre d'outils pour la page affichée (les onglets en arrière-plan sont suspendus par le système).

Confidentialité et sécurité

  • Bloqueur de pubs et traqueurs (listes EasyList et uBlock) actif partout, avec un compteur par onglet ; désactivez-le pour un site depuis le bouclier de la barre d'adresse ou les infos sur le site.
  • HTTPS uniquement : chaque adresse passe en https ; si le site ne le permet pas, une page vous demande avant de continuer.
  • Fenêtres surgissantes : une page ne peut ouvrir une fenêtre qu'après un vrai clic.
  • Autorisations (caméra, micro, notifications…) demandées site par site, révocables dans les infos sur le site.
  • Moins d'empreinte : Global Privacy Control, identité de navigateur sans trace d'Electron, langue envoyée aux sites uniformisable (Paramètres, Confidentialité).
  • Cookies tiers bloquables, données d'un site effaçables (commande « Effacer les données du site », ou Paramètres, Données des sites).

Fenêtres privées

Ctrl Maj N (⇧ ⌘ N) : chaque fenêtre privée a sa session en mémoire, effacée à sa fermeture. Ni historique, ni session restaurée, ni autorisation mémorisée, ni mot de passe proposé, ni extension, et rien de synchronisé.

Ce qui reste chez vous

Historique, favoris, mots de passe, sessions et réglages restent dans votre profil local. Rien n'est envoyé ailleurs, sauf la synchronisation si vous l'activez, chiffrée de bout en bout, et la vérification des mises à jour (GitHub). Les pages internes browser:// ne sont jamais accessibles aux sites web.

Apparence et thèmes

Paramètres, Apparence : thème clair, sombre ou automatique, couleur d'accent et couleur secondaire (la palette dérivée reste lisible), arrière-plan, police, densité, arrondis, ombres, animations réduites, curseur main. Disposition : barre latérale à gauche ou à droite, largeur, marge autour de la page.

  • Galerie : huit thèmes prêts à l'emploi, avec un aperçu.
  • Partager votre thème : code browser-theme:v1:… à copier, fichier .browsertheme ou QR code. Pour importer, collez un code ou choisissez un fichier : un aperçu s'affiche avant d'appliquer.
  • Thème dynamique (désactivé par défaut) : l'accent prend la couleur du site affiché (sa couleur de thème, sinon celle de son icône), ajustée pour que le texte reste lisible ; sur les autres pages, la couleur de l'espace revient. Jamais en fenêtre privée.
  • Mode zen : Ctrl Maj B (⇧ ⌘ B), la page seule, bord à bord.

Raccourcis clavier

Raccourcis par défaut. Chacun peut être changé ou retiré dans Paramètres, Raccourcis clavier : appuyez sur la nouvelle combinaison ; un conflit avec une autre commande vous est signalé, et les combinaisons réservées par le système sont refusées.

Mises à jour

Browser vérifie les nouvelles versions 30 secondes après le démarrage puis toutes les 6 heures, les télécharge en arrière-plan et les installe au prochain redémarrage, ou tout de suite avec « Redémarrer pour mettre à jour » (barre latérale, menu Fichier ou barre universelle). Paramètres, Mises à jour : téléchargement automatique, canal Stable ou Bêta, « Rechercher des mises à jour ».

  • Windows : automatique avec l'installateur ; la version portable .zip se met à jour à la main.
  • Linux : l'AppImage se met à jour seule, le paquet .deb non.
  • macOS : tant que l'app n'est pas signée par un certificat Developer ID, Browser affiche « Mise à jour manuelle requise » avec un lien vers la nouvelle version.

Vos onglets, favoris et réglages sont conservés d'une version à l'autre.

Profils, sauvegarde et plantages

  • Reprise après plantage : la session (fenêtres, espaces, onglets, dossiers, vue scindée) est enregistrée en continu. Si Browser s'est mal fermé, la page d'accueil propose « Restaurer la session ? » : tout restaurer, choisir les fenêtres ou ignorer. Paramètres, Comportement, « Au démarrage » : reprendre où vous en étiez ou la page d'accueil.
  • Récemment fermés : menu « … », Historique ; « Rouvrir la fenêtre fermée » avec Ctrl+Alt+Maj+T.
  • Page plantée : un onglet dont le processus s'arrête affiche « Cette page a planté » avec « Actualiser » ; le reste du navigateur continue.
  • Gestionnaire de tâches (Maj+Échap, browser://tasks) : mémoire et processeur de chaque onglet, extension et service, triables ; « Terminer le processus » arrête un onglet gourmand.
  • Imprimer (Ctrl+P) : aperçu avec pages, orientation, marges, échelle, arrière-plans, puis « Enregistrer en PDF » ou une imprimante.
  • Profils (browser://profiles) : chaque profil a ses réglages, historique, favoris, mots de passe, sessions et sa synchronisation. « Ouvrir » ouvre une fenêtre de ce profil ; « Choisir le profil au démarrage » affiche la liste au lancement.
  • Sauvegarde : « Exporter le profil… » écrit un fichier .browserbackup (les mots de passe seulement si vous le cochez, chiffrés par une phrase secrète ; jamais les cookies). « Importer une sauvegarde… » montre son contenu, puis fusionne ou remplace.

Synchronisation chiffrée

Favoris (et la grille des favoris), historique des 90 derniers jours, onglets ouverts, espaces, thème, moteur de recherche, page d'accueil et boosts se synchronisent entre vos ordinateurs et votre téléphone. Tout est chiffré sur l'appareil (XChaCha20-Poly1305) avant l'envoi : le serveur ne voit que des données illisibles. Les fenêtres privées et les mots de passe ne sont jamais synchronisés.

1. Déployer votre serveur

Aucun serveur n'est fourni : la synchronisation reste désactivée tant que vous n'en avez pas. Le dossier server/ du dépôt contient un petit relais sans dépendance (Node 22, Docker) et des guides pour un VPS avec Caddy, Fly.io ou Render : voir server/README.md. Choisissez un REGISTRATION_SECRET, sans quoi n'importe qui pourrait créer un compte sur votre serveur.

2. Premier appareil

  1. Paramètres (Ctrl ,), Synchronisation, Premier appareil.
  2. Collez l'adresse du serveur (https://sync.exemple.fr) et le code d'inscription, puis « Activer la synchronisation ». La clé de chiffrement est créée sur cet appareil.

3. Jumeler les autres

  1. Sur le premier appareil : « Afficher le code de jumelage ». Ce code donne accès à toutes vos données synchronisées : ne le partagez pas.
  2. Sur le téléphone : Paramètres, Synchronisation, « Scanner le code de jumelage » (ou collez le code texte).
  3. Sur un autre ordinateur : Rejoindre un compte existant et collez le code.

La synchronisation a lieu au démarrage, quelques secondes après chaque changement, toutes les 5 minutes, et sur le téléphone à chaque retour au premier plan (ou « Synchroniser maintenant »). Les onglets de vos autres appareils apparaissent dans la barre universelle et dans la vue des onglets du téléphone.

Envoyer un onglet à un appareil

Clic droit dans la page, « Envoyer à un appareil », puis choisissez l'appareil jumelé. L'adresse voyage chiffrée de bout en bout et expire après 7 jours si elle n'est pas reçue. L'ordinateur destinataire l'ouvre en arrière-plan avec une notification ; le téléphone demande « Ouvrir » ou « Plus tard » et la garde sous « Autres appareils ». Jamais depuis une fenêtre privée.

  • Déconnecter cet appareil : arrête la synchronisation ici, les données locales restent.
  • Réinitialiser (code perdu, appareil volé) : efface le compte sur le serveur et en crée un nouveau avec une nouvelle clé ; jumelez à nouveau vos appareils.

Pour essayer en local : cd server && npm ci && npm run build && npm start, puis l'adresse http://<IP-du-PC>:8787 (http n'est accepté que sur le réseau local).

Dépannage et questions

Windows affiche « Windows a protégé votre ordinateur ».
C'est SmartScreen, qui avertit pour un programme non signé ou encore peu téléchargé. Tant que les paquets ne sont pas signés : « Informations complémentaires », puis « Exécuter quand même ». Vérifiez le fichier avec SHA256SUMS.txt si vous le souhaitez. La signature (Azure Trusted Signing) est prête et sera activée dans une prochaine version ; même signé, un nouvel exécutable peut être signalé quelques jours, le temps d'acquérir sa réputation.
Netflix, Disney+, Prime Video ou Spotify refusent de lire.
Ils exigent le module de contenus protégés Widevine. Vérifiez Paramètres, Confidentialité, « Contenus protégés (DRM) » : l'interrupteur doit être activé et une version de Widevine affichée. Au tout premier lancement, le module se télécharge en quelques secondes ; relancez le navigateur s'il indique « installation en cours ». Sous Linux, Widevine n'est pas disponible. Certains services réservent la haute définition aux navigateurs dont la plateforme est vérifiée (signature VMP des versions publiées).
Google refuse la connexion (« Ce navigateur ou cette application n'est peut-être pas sécurisé »).
Browser se présente comme Google Chrome de la même version, ce qui suffit d'ordinaire. Si Google refuse malgré tout, mettez Browser à jour, réessayez depuis accounts.google.com plutôt que depuis une fenêtre surgissante, et désactivez les protections pour ce site le temps de la connexion. Signalez-le sur GitHub en précisant la version : les contrôles de Google évoluent.
Un site ne trouve pas ma clé d'accès (passkey) ou ma clé de sécurité.
Sous Windows, la connexion passe par Windows Hello : vérifiez qu'il est configuré. Sous macOS et Linux, seules les clés de sécurité USB sans code PIN fonctionnent ; Touch ID, le trousseau iCloud et la connexion avec un téléphone ne sont pas disponibles. Voir « Adresses, cartes et clés d'accès ».
Je ne reçois pas les notifications d'un site fermé.
Normal : les notifications « push » en arrière-plan ne sont pas prises en charge. Gardez l'onglet ouvert (il peut être en arrière-plan), et vérifiez que « Ne pas déranger » est désactivé.
macOS dit que l'application ne peut pas être ouverte.
Clic droit sur Browser dans Applications, « Ouvrir » ; ou Réglages Système, Confidentialité et sécurité, « Ouvrir quand même ».
L'AppImage ne se lance pas sous Linux.
Rendez-la exécutable (chmod +x). Sur certaines distributions récentes, installez aussi libfuse2.
En développement, npm run dev ne trouve pas Electron.
Electron 44 ne télécharge plus son binaire à l'installation : scripts/ensure-electron.mjs le fait au postinstall et avant npm run dev. Relancez npm install (ou node scripts/ensure-electron.mjs), en vérifiant l'accès réseau ou le proxy.
npm install échoue sur un conflit de dépendances.
Le fichier .npmrc du dépôt active legacy-peer-deps ; lancez la commande à la racine du dépôt. Sous Windows, évitez un dossier synchronisé par OneDrive.
Que voit Anthropic quand j'utilise l'assistant ?
Seulement ce que vous lui demandez de lire, au moment où vous le demandez : le titre, l'adresse et le texte de la page (ou de la sélection, ou des onglets comparés) et votre question, envoyés directement par le navigateur avec votre clé, jamais les champs de formulaire ni les mots de passe. Un avertissement le rappelle avant le premier envoi, et à chaque fenêtre privée. Rien ne passe par nos serveurs : la clé est chiffrée par le système sur l'appareil, jamais synchronisée ; les conversations ne sont ni écrites sur le disque ni synchronisées. L'utilisation des données par Anthropic suit ses conditions de l'API.
Un site ne fonctionne pas correctement.
Désactivez les protections pour ce site (bouclier de la barre d'adresse), puis rechargez. Si le site refuse le https, la page HTTPS uniquement propose de continuer.
Un onglet se recharge quand j'y reviens.
Il était en veille pour libérer la mémoire. Allongez le délai ou choisissez « Jamais » dans Paramètres, Comportement.
Un onglet a disparu.
Il a peut-être été archivé : commande « Onglets archivés » ou filtre de la barre universelle.
La synchronisation ne démarre pas.
Vérifiez l'adresse (https obligatoire hors réseau local), le code d'inscription, et que le serveur répond. L'état et la dernière erreur s'affichent dans Paramètres, Synchronisation.
Les mots de passe ne sont pas proposés à l'enregistrement.
Jamais en fenêtre privée ; sous Linux, un trousseau système (GNOME Keyring, KWallet) est nécessaire, sinon rien n'est enregistré.
Où est mon profil ?
Dans le dossier de données de l'application (%APPDATA%\Browser, ~/Library/Application Support/Browser ou ~/.config/Browser). Il est conservé à la désinstallation.
