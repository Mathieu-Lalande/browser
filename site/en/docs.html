Installation

Download the latest version from the download page: the main button detects your system. All the files are also in the versions published on GitHub, with SHA256SUMS.txt to check them.

Windows 10 and 11

  1. Download Browser-Setup-<version>-x64.exe (or -arm64.exe for Windows on ARM).
  2. Run it. Choose an installation for you alone (without administrator rights, the default) or for all users.
  3. If SmartScreen shows “Windows protected your PC”: “More info”, then “Run anyway” (the packages aren't signed yet).

The installer creates a Start menu shortcut, offers a desktop shortcut and uninstalls from Settings, Apps; your profile is kept. The portable version Browser-<version>-win-x64.zip runs without installation but doesn't update itself.

macOS 12 or later

  1. Download Browser-<version>-mac-arm64.dmg (Apple Silicon) or -mac-x64.dmg (Intel).
  2. Open the .dmg and drag Browser to Applications.
  3. On first launch, right-click Browser, then “Open” (the app isn't notarized yet), or allow it in System Settings, Privacy & Security.

Linux 64-bit

  • AppImage: make the file executable (chmod +x Browser-*.AppImage), then run it. It updates itself.
  • .deb package (Debian, Ubuntu): sudo apt install ./Browser-*.deb. Manual updates.

Check a file

Compare the checksum of the downloaded file with the one in SHA256SUMS.txt: sha256sum <file> (Linux), shasum -a 256 <file> (macOS) or Get-FileHash <file> (PowerShell).

To build Browser yourself (Node.js 22, npm install then npm run dev), follow docs/INSTALL.md.

Mobile app

The iPhone and Android app isn't in the stores yet. Two ways to use it right now:

With Expo Go (the simplest)

  1. Install Expo Go (App Store or Play Store), an up-to-date version (SDK 58).
  2. On a computer with Node.js: clone the repository, then cd mobile, npm install and npx expo start.
  3. Scan the QR code (camera on iPhone, Expo Go on Android). Same Wi-Fi required, otherwise npx expo start --tunnel.

As a compiled version (TestFlight, APK)

With EAS Build, Expo's build service (no Mac needed): eas build --platform ios then eas submit for TestFlight (Apple Developer account required), or eas build --platform android --profile preview for an .apk to install directly. The details are in docs/INSTALL.md.

What the app does

  • Address bar at the bottom, folded while scrolling; swipe it to switch tabs.
  • Full-screen search (same engine as the desktop's universal bar), tab view as a grid per space, folders, favorites and archiving.
  • Private browsing, HTTPS only, reader mode, a site's desktop version, link preview with a long press.
  • Passwords in the phone's keychain, boosts (without the hiding tool), shareable themes.
  • Mini player above the toolbar when the page plays media.
  • Encrypted sync with the desktop (pairing by QR code).
  • French or English, following the phone's language (Settings, Appearance, Language to choose).

The full ad and tracker blocker (blocked requests, per-site shield) needs the compiled app; in Expo Go, only ad slots are hidden and cookie banners refused.

First steps

On first launch, the guided tour (browser://welcome) offers five steps, all optional: a theme, importing from the browser found on the computer, Browser as the default browser, then the essentials (universal bar, spaces, link preview, compact mode). The arrow keys go from one step to the next, Esc or “Skip” close it. It doesn't come back afterwards; Help, Guided tour reopens it.

Browser speaks French and English: it follows your system's language (English when the system speaks neither). To choose: Settings, Appearance, Language; the whole interface, menus included, switches at once.

Browser's window has three areas:

  • The sidebar (on the left, or on the right in Settings, Layout): address bar, favorites grid, pinned tabs, folders and tabs of the current space, and the spaces at the bottom. Hide it with Ctrl S (⌘ S).
  • The page, with a small adjustable margin around it, or edge to edge.
  • The universal bar that floats above the page when you type Ctrl K (⌘ K).

Type an address or a search in the address bar (Ctrl L): search goes through DuckDuckGo by default (Settings, Search to change it). The bar's buttons (copy link, zoom, bookmark, protections, page options) appear on hover; the padlock stays visible and opens the site info.

The start page shows a greeting, the clock and your most visited sites; everything is set in Settings, Start page. Settings (Ctrl ,) apply live and can also be found by typing their name in the universal bar.

At startup, Browser restores your session: tabs come back, loaded only when you open them.

Default browser, history, import

Default browser

On first launch, the start page offers once to make Browser your default browser (“Later” makes it go away). The setting is in Settings, Behavior, Default browser. On Windows 10 and 11, the button opens Windows Settings on Browser's page: choose it for web links and, if you wish, for HTML and PDF files. On macOS, the system asks you to confirm; on Linux, Browser becomes the handler of http and https links.

A link clicked in another app opens, when Browser is already running, in a mini window; an HTML or PDF file opened from the file manager (or a link, with the setting off) opens in a new tab of the last normal window used (never in a private window).

PDF viewer

PDFs show directly in the tab, online as well as on your disk, with Chromium's built-in viewer (zoom, find, print, download). A PDF sent as an attachment by the site is downloaded, as before.

History

Ctrl H (⌘ Y), the “…” menu, History, All history, or @h in the universal bar open browser://history: visited pages day by day, a search, deleting a page or a selection, and Clear history for the last hour, today, the last 7 days or everything. Private windows neither save nor show history.

Import from another browser

Settings, Data, Import… (or browser://import) detects Chrome, Edge, Brave, Vivaldi, Opera, Chromium, Firefox and Arc and their profiles. Choose what to bring over: bookmarks (kept in folders of the same name), history, search engine, and for Arc the bar's favorites and the pinned tabs of each space. Nothing is imported twice.

Other browsers' passwords are encrypted with a system key Browser must not read: export them as CSV from the other browser (Chrome, Edge: Password Manager, Export; Firefox: Passwords, “…”, Export), choose the file in the import page, then delete it. Safari isn't imported.

Mini window, energy saver, Windows

Mini window

A link opened from another app (messaging, email…) shows in a small frameless window: the site and the page title, then “Always on top”, “Copy link”, “Open in browser” (Ctrl O, ⌘ O) and “Close” (Ctrl W). “Open in browser” moves the page, as it is and without reloading it, into a tab of the last window used; closing the mini window forgets the page (nothing in history). Settings, Behavior, “Open external links in a mini window” (on by default).

Energy saver

Settings, Behavior, Energy saver: off, on battery (the default) or always. When on, it puts inactive tabs to sleep after 5 minutes at most, slows down background pages, spaces out tab previews, stops following the media of hidden tabs and turns off animations. An icon (battery or sprout) shows it in the window bar.

Windows and macOS

  • Jump List (right-click on the taskbar icon): New tab, New private window, your spaces and recent files.
  • Taskbar: download progress and a badge while they run; Back, Forward and New tab buttons under the window preview.
  • Mica effect (Windows 11, Settings, Appearance, on by default): the desktop background shows through behind the sidebar. No effect on Windows 10.
  • macOS: the Dock icon's menu offers the same shortcuts.

Tabs

  • Open, close: Ctrl T, Ctrl W. Where a new tab opens and which one shows after closing: Settings, Behavior.
  • Pin: right-click, “Pin the tab”, or double-click the tab. A pinned tab stays at the top of the bar.
  • Duplicate with its history: Ctrl Shift K.
  • Switch tabs: Ctrl Tab / Ctrl Shift Tab, or Ctrl 1…9.
  • Preview on hover: leave the pointer on a tab, a favorite or an icon of the compact rail: a card shows the page's thumbnail, its title, the site, and whether the tab plays sound or is asleep. Move from one tab to another and the card follows at once. Can be turned off in Settings, Layout, “Tab preview on hover”.
  • With the keyboard: the tab list is a single tab stop; ↑ ↓, Home End to move, Enter to show, Delete to close.
  • Tab menu (right-click): pin, duplicate, split view, move to a space or a folder, put to sleep, mute, close.
  • Reopen the closed tab: Ctrl Shift T (⇧ ⌘ T), several times to go further back (last 25, never written to disk).
  • Select several tabs: Ctrl + click (⌘ + click on Mac), or “Select all tabs”. An action bar appears: new folder, move to a space, close, cancel (Esc).

Sleeping tabs

A tab inactive for the chosen delay (Settings, Behavior: never, 15 min, 30 min…) is put to sleep: its memory is freed and it reloads when you come back to it. Never for a tab playing sound, waiting for a permission or holding a form in progress. The “Put tab to sleep” and “Put other tabs to sleep” commands do it right away. A sleeping tab's tooltip and the task manager (Shift Esc) show roughly how much memory sleeping freed: an estimate, measured just before the page closed.

Menus and gestures

The app's “…” menu

The “…” button at the head of the navigation row opens the full menu: sync status, new tab and windows, zoom row (− % +) and full screen, recent history, bookmarks, downloads, passwords, extensions and themes, print, save page, find in page, more tools (screenshots, video, reading, boost, page source…), settings, help (shortcuts, about, report a problem) and quit. With the keyboard: arrows to move, → or Enter to open a submenu, ← or Esc to go back.

Context menus

  • Empty space of the sidebar (right-click): new tab, new folder, reload, bookmark, select all tabs, reopen the closed tab, compact mode, switch the sidebar's side, edit the space.
  • Space chip (right-click): rename, icon and color, move left or right, delete (after confirmation).
  • Page (right-click): back, forward, reload and bookmark first, then “Save page as…” (complete HTML or MHTML), “Select all”, “Screenshot”, “View page source” (Ctrl U), “Send to a device” and “Inspect”. On a link: new tab, background, split view, another space, private window, preview, copy.

Compact mode

“Compact mode” command (sidebar menu or universal bar): the sidebar becomes a rail of icons that unfolds on hover. Zen mode takes precedence.

Gestures on the page

  • Pinch on the touchpad or Ctrl + wheel: page zoom, remembered per site like Ctrl +.
  • Two-finger swipe horizontally: previous or next page. An arrow follows the gesture; it only triggers when the page can no longer scroll in that direction.
  • Full screen: F11 (⌃ ⌘ F). Print: Ctrl P (⌘ P).

Spaces and gestures

A space groups tabs around a context (work, studies, leisure), with its name, its icon and its accent color. Create one with the “New space” button, next to the space chips at the bottom of the sidebar, or the command of the same name.

  • Switch spaces: click its icon, Ctrl Alt ← / →, or Ctrl Alt 1…9 (⌥ ⌘ on Mac).
  • Swipe: slide two fingers horizontally on the touchpad, with the pointer on the sidebar, or one finger on a touch screen. The list follows the gesture; release past a quarter to switch spaces.
  • Isolated space: in the space editor, tick isolation to give it its own cookies and sign-ins, like a container (two accounts of the same site side by side).
  • Move a tab: right-click the tab, “Move to”.
  • Edit, reorder, delete a space: right-click its chip, or the “Edit space theme” command.

In the page, a two-finger swipe (macOS) or Alt ← / → navigates back and forward.

Split view

Show two to four tabs side by side: Ctrl Shift \ (⇧ ⌘ \) pairs the active tab with the next one, and the same shortcut leaves the view. From a tab's menu, “Split view”; from the universal bar, Shift Enter opens a result beside.

Drag the dividers to adjust the panes; the layout is restored at startup.

Folders, favorites, archiving

Folders

“New folder” command or a tab's menu. Drag and drop tabs into it; a folder can contain others (4 levels), have an icon and collapse (the active tab stays visible). A link opened from a tab in a folder stays in the same folder.

Bookmarks and favorites

  • Ctrl D adds or removes the page from bookmarks (managed in Settings, Data).
  • “Add to favorites (all spaces)” puts the site in the favorites grid, at the top of the sidebar, shared by every space.

Automatic archiving

Tabs you no longer open are archived after the chosen delay (Settings, Behavior: never, 12 h, 24 h, 7 days by default, 30 days). Never the tab on screen, a pinned one, one in the favorites grid, one playing sound or in split view. Find them with the “Archived tabs” command (browser://archive) or the universal bar's filter.

Universal bar

Ctrl K (⌘ K) opens a fuzzy search over the tabs of every space, the favorites grid, bookmarks, history, commands (with their shortcut), settings, the tabs of your other devices and archived tabs. Nothing is sent to the search engine while you type. Commands and settings are found by their French and English names alike.

Instant answers

Computed on your computer, shown first; Enter copies the result.

  • Calculations: 12*7+3, (1.5+2)^2, 15%.
  • Conversions: 12 km in miles, 350 F to C, 2 TB in GB (length, mass, temperature, volume, speed, data).
  • Time in a city: time in Tokyo; bases: 0xff, 255 in binary.

Link preview

Shift + click on a link, or right-click then “Link preview”: the page opens in a floating card above the tab. Keep it with “Open in a tab” (without reloading) or “Open in split view”, or close it with Esc or a click beside it. Nothing is added to history.

On the phone, a long press on a link offers the preview in a sheet.

Reader mode and mobile site

On an article, Ctrl Alt R (⌥ ⌘ R) or Page options, “Reader mode”: the text and its images alone, in a calm layout. The same shortcut goes back to the page.

“Request mobile site” (Page options) reloads the site as a phone would see it; in the mobile app, the opposite: “desktop site”. On the phone too, reader mode shows the article's first images, downloaded without cookies.

Translation

Off by default: to translate, the page's text is sent to an online service. Choose it in Settings, “Translation”: DeepL (Free or Pro API key), LibreTranslate (your server or a public one, optional key) or Google Cloud Translation (API key). “Test” checks the configuration. Keys are encrypted by the system (keychain) and never shown again.

On a page in another language, the translate icon appears in the address bar: choose the languages (“Detect” lets the service recognize the language), then “Translate”. The first time, the browser reminds you that the text goes to the chosen service. Also: Ctrl Alt T (⌥ ⌘ T), the “…” menu or a right-click on the page.

  • The visible part is translated first, then the rest and the content that arrives later; code, scripts, form fields and editable areas are never sent.
  • “Show original” puts back the page's exact text, without reloading it.
  • “Always translate this language” and “Never for this site” can be found and removed in the settings.
  • Private windows: confirmation asked for each window, rules kept in memory only.
  • On the phone: page menu, “Translate the page” then “Show original”; the service and its key are set in Settings, “Translation”.

AI assistant

Optional and off by default. The assistant uses Anthropic's Claude with your own API key (to create on console.anthropic.com, billed to your account): Settings, “AI assistant”, turn it on, paste the key, then “Test”. Default model: Claude Opus 5.5, fast; Claude Fable 5.1 is the “more powerful” option.

Open the panel next to the page with Ctrl Alt A (⌥ ⌘ A), the “…” menu or a right-click. Quick actions: “Summarize the page”, “Key points”, “Explain the selection”, “Translate the selection”, or a question about the page. Select several tabs (Ctrl+click) then the assistant icon to compare them. In the universal bar, @ia followed by a question sends it, with or without the page. Prompts follow the interface language, and so do the answers.

  • Each request shows what was sent (page titles, “truncated” for a page that is too long).
  • Answers stream in: “Stop” interrupts them; “Copy” and “Add to notes” keep them.
  • Conversations stay in memory, per tab; they are erased when the page changes unless “Keep conversations” is on.
  • On the phone: page menu, “AI assistant” (summary, key points, question), same settings.

Web panels

Pin a web app (WhatsApp Web, Messenger, Spotify, ChatGPT, Gmail… or any address) to the sidebar: the + button above the bar's footer offers suggestions, the current page or an address to type. A click on its icon opens it next to the page, a second one hides it; Ctrl Shift E (⇧ ⌘ E) shows or hides the last panel opened.

  • The panel stays loaded in the background: the number of unread messages from its title shows on its icon.
  • Drag its edge to widen it; “Mobile site” asks for the site's narrow layout.
  • Right-click the icon: reload, mobile site, move up, move down, remove. Each panel has its own session (its cookies don't mix with tabs); removing it erases it.
  • Never in a private window. The list can be synced between your computers (Settings, Sync, “Web panels”, off by default).

Read later

Keep a page for later with the address bar's button (on hover), a right-click on the page, the universal bar or Ctrl Shift D (⇧ ⌘ D). The article's text (the reader mode one) is saved with it: it can be read even offline.

  • browser://reading-list (app menu, “Reading list”): unread, all or read; “Read” opens the offline copy, the link icon opens the page online.
  • The list and its texts are synced, end-to-end encrypted, with your devices; on the phone: page menu, “Read later” and “Reading list”.
  • Nothing is added from a private window or tab.

Notes and highlights

Select text in a page, then right-click, “Highlight” and a color (yellow, green, blue or pink), or Ctrl Shift H (⇧ ⌘ H) with the last color chosen. The passage stays highlighted on every visit, even if the page has changed a little.

  • A click on a highlighted passage opens its card: color, note, “Copy”, “Delete”.
  • “Page notes” (Ctrl Alt N) opens a panel next to the page: a free note for the page and the list of its passages; a click scrolls the page to the passage.
  • browser://notes gathers everything, grouped by site: search, filter by color, Markdown or JSON export, deletion. In the universal bar, @n searches your passages and notes.
  • Optional sync (Settings, “Sync”, “Notes and highlights”), end-to-end encrypted like the rest.
  • Private windows: notes stay in memory and disappear when the window closes.
  • On the phone: select text then “Highlight”; tap a passage to change its color, write a note on it or delete it; “Page note” is in the page menu; the list is in Settings, “Notes and highlights”.

Boosts

A boost customizes a site (or a domain and its subdomains, *.example.com):

  • color filters (invert, gray, sepia, brightness, contrast) and font;
  • hidden elements: “Hide elements” command, then click what gets in the way (Esc to finish);
  • custom CSS, and an optional script (off by default, with a warning).

Create and edit your boosts from Page options, “Site boost”, or the browser://boosts page (“Boosts” command). They are synced; a script received from another device stays off until you accept it.

Passwords

  • Save: after a sign-in, Browser offers to save the credentials (or “Never for this site”).
  • Fill: only when you ask, with the key that appears in the address bar on a known site, or “Fill the password” in the page menu. A password is only offered on the exact site where it was saved.
  • Manage: “Passwords” command (browser://passwords): search, show, edit, delete, CSV export compatible with Chrome and Firefox.

Passwords are encrypted by the system keychain (Windows, macOS, Linux). No prompt in a private window.

Sync (off by default): Settings, “Sync”, “Sync passwords” (on the phone: Settings, “Passwords”). Accounts and the “Never for this site” list are end-to-end encrypted: the server sees nothing, and nothing is written in plain text outside the keychain. But any device paired with your pairing code can read them: keep this code secret. When an entry changes on two devices, the most recent wins; a deletion propagates.

Addresses, cards and passkeys

  • Save: after sending a shipping or payment form, Browser offers “Save this address?” or “Save this card?”. Fields are recognized in French and English (France/Europe, United Kingdom, North America address formats).
  • Fill: when entering a recognized field, a list offers your addresses or cards; also “Fill an address” in the page menu (desktop and phone).
  • Manage: Settings, “Addresses and payments”. Showing a card's full number asks for Touch ID (Mac) or a system confirmation.

Everything is encrypted by the system keychain (phone: iOS keychain / Android Keystore). The security code (CVC) is never saved. Nothing is offered or saved in private browsing. Addresses can be synced (off by default, end-to-end encrypted); cards never leave the device.

Passkeys and security keys

  • Windows: everything goes through Windows Hello (this PC's passkeys, USB/NFC keys with their PIN, sign-in with a phone by QR code).
  • macOS: USB security keys without a PIN work. Touch ID and iCloud passkeys aren't available in the current versions (a version signed with a dedicated keychain entitlement is needed); no sign-in with a phone.
  • Linux: USB security keys without a PIN (the user must have access to the device, udev rules); no built-in authenticator.
  • Several accounts for a site: Browser asks which one to use.

Notifications and spelling

  • Notifications: a site must first ask for permission (bar above the page). They show with the site's name and icon; a click brings the tab back. To change your mind: Site info (Allow, Block, Reset).
  • Do not disturb: Settings, Notifications.
  • Spelling: Settings, Spelling: dictionary languages (Windows, Linux; macOS follows the system languages), words added to the dictionary; suggestions and “Add to dictionary” on right-click.

“Push” notifications received when the site is closed (service workers, Web Push) aren't supported by Electron: only open tabs can show them.

Extensions

Open an extension on the Chrome Web Store: the grayed-out “Add to Chrome” button becomes “Add to Browser”, in the same place (also in the address bar). The browser downloads the extension from Google, checks its signature, then shows you what it will be able to do before installing it; the button follows each step (download, verification, installation) and offers “Try again” if it fails. Once added, “Pin” puts its button under the address bar. Store extensions update every day (option on the page) or with “Update extensions”.

“Extensions” command (browser://extensions, also from Settings, Behavior): also add an unpacked folder or a .zip / .crx file, or drop them on the page. Search, turn on, turn off, pin or remove them; “Details” shows the sites it can access, the permissions, the size, the last update check and opens the extension's options. Extension buttons show under the address bar; the puzzle piece lists them all, a click opens the extension's window.

The browser completes Electron's chrome.* APIs: tabs and windows (open, close, list), button badges, titles and icons, clicks on a button without a window, items added to the page context menu (under the extension's name, kept from one launch to the next), notifications. An extension only reads a tab's address and title when it has the permission. Its keyboard shortcuts work while it is enabled and a browser window has focus (never system-wide); the browser's own shortcuts come first, and “Details” shows an inactive shortcut and what already uses it. No extension runs in a private window (Electron doesn't load extensions in a session kept in memory).

Page options, screenshots and video

The Page options button, at the end of the address bar (Ctrl Shift O), gathers: copy link, zoom (−, percentage to go back to the default, +), screenshots, video, reader mode, mobile site, site boost, site info and the page's QR code.

  • Visible area: Ctrl Shift S (⇧ ⌘ S).
  • Full page: Ctrl Alt S (⌥ ⌘ S), without scrolling the page.
  • An element: “Screenshot of an element”, hover then click (Esc cancels).

A preview shows at the bottom right: “Copy” or “Save” (PNG, in the downloads folder).

Tab video: Ctrl Alt V (⌥ ⌘ V) starts and stops recording (the tab's picture and sound only). A red dot and a timer stay visible in the address bar; when stopped, the WebM file is offered to you.

Downloads, find, zoom, media

  • Downloads: saved without a dialog (or always ask where, Settings, Downloads), with pause, resume and cancel; a download interrupted by closing the browser picks up where it stopped (“Resume”), when the server allows it. Programs and scripts wait for your confirmation; nothing is opened automatically. List: Ctrl Shift J (⌥ ⌘ L) or browser://downloads.
  • Find in page: Ctrl F, then Enter / Shift Enter, F3 or Ctrl G for the next match. The counter and case are kept per tab.
  • Zoom: Ctrl + / - / 0, pinch or Ctrl + wheel, remembered per site; default zoom in Settings, Appearance.
  • Media: Ctrl M mutes the tab; “Picture in picture” detaches the video, and does it by itself when you leave a tab playing a video if “Automatic picture in picture” is on (Settings, Behavior; sites that forbid it are respected); Ctrl Alt P (⌥ ⌘ P) pauses everything.

Pausing media

When a tab other than the one on screen plays music or a video, a mini player appears at the bottom of the sidebar: artwork, title and artist announced by the site, a clickable progress bar, play/pause, “Skip ahead 10 s”, picture in picture for a video, and close (pauses and hides the player). A click on the title shows the tab, even in another space. A paused source stays offered for 5 minutes.

  • Several sources: a counter opens the list of all of them, each with play/pause, sound and close.
  • “Pause all media” (palette, menu or shortcut) stops every tab of every window.
  • Media keys of the keyboard: they drive the last active player.
  • Compact mode: a play/pause button in the rail. Also works in a private window, without saving anything.
  • Phone: a bar above the toolbar for the page on screen (background tabs are suspended by the system).

Privacy and security

  • Ad and tracker blocker (EasyList and uBlock lists) on everywhere, with a counter per tab; turn it off for a site from the address bar's shield or the site info.
  • HTTPS only: every address goes to https; if the site doesn't allow it, a page asks you before continuing.
  • Pop-ups: a page can only open a window after a real click.
  • Permissions (camera, microphone, notifications…) asked site by site, revocable in the site info.
  • Less fingerprinting: Global Privacy Control, a browser identity without any trace of Electron, a standardizable language sent to sites (Settings, Privacy).
  • Third-party cookies can be blocked, a site's data can be cleared (“Clear site data” command, or Settings, Site data).
  • Cookie banners refused out of the box on common consent platforms (OneTrust, Didomi, Cookiebot, Quantcast, Usercentrics, Axeptio, Sirdata, CookieYes, iubenda, Complianz, Google, Klaro, Osano, TrustArc, Termly): “Reject all” or “Continue without accepting”, otherwise the banner is hidden. Never “Accept”. Can be turned off per site (site info).
  • Secure DNS (DNS over HTTPS): automatic, Cloudflare, Quad9, NextDNS or a server of your own (Settings, Privacy). It applies to the whole browser; a company or parental DNS filter then no longer applies.
  • Fingerprinting: Standard level (reduced Chrome identity) or Strict (standardized language, no detailed client hints, fonts, screens and MIDI devices refused without asking). Canvas/WebGL drawing isn't scrambled: a browser that injects no script into pages can't do it.

Dashboard and site settings

browser://privacy (“…” menu, Library, or the site info) shows what the protections did over the last 30 days: trackers and ads blocked, banners refused, connections upgraded to HTTPS, third-party cookies blocked, fingerprinting attempts countered, most frequent sites and trackers. Only totals per day and per site are kept, on the device; private windows don't count. browser://site-settings gathers the decisions made site by site (permissions, zoom, protections, JavaScript, muted sound, cookie banners, third-party cookie exceptions), with a search and a reset per site, and the default behaviors (autoplay: allow, muted, block).

Private windows

Ctrl Shift N (⇧ ⌘ N): each private window has its own in-memory session, erased when it closes. No history, no restored session, no remembered permission, no password offered, no extension, and nothing synced.

What stays with you

History, bookmarks, passwords, sessions and settings stay in your local profile. Nothing is sent anywhere else, except sync if you turn it on, end-to-end encrypted, and the update check (GitHub). The internal browser:// pages are never accessible to websites.

Appearance and themes

Settings, Appearance: interface language, light, dark or automatic theme, accent color and secondary color (the derived palette stays readable), background, font, density, corner radius, shadows, reduced motion, hand cursor. Layout: sidebar on the left or on the right, width, margin around the page.

  • Gallery: eight ready-to-use themes, with a preview.
  • Share your theme: a browser-theme:v1:… code to copy, a .browsertheme file or a QR code. To import, paste a code or choose a file: a preview shows before applying.
  • Dynamic theme (off by default): the accent takes the color of the site on screen (its theme color, otherwise its icon's), adjusted so the text stays readable; on other pages, the space's color comes back. Never in a private window. On the phone: Settings, “Site color” (theme color only).
  • Zen mode: Ctrl Shift B (⇧ ⌘ B), the page alone, edge to edge.

Updates

Browser checks for new versions 30 seconds after startup and then every 6 hours, downloads them in the background and installs them at the next restart, or right away with “Restart to update” (sidebar, File menu or universal bar). Settings, Updates: automatic download, Stable or Beta channel, “Check for updates”.

  • Windows: automatic with the installer; the portable .zip version is updated by hand.
  • Linux: the AppImage updates itself, the .deb package doesn't.
  • macOS: as long as the app isn't signed with a Developer ID certificate, Browser shows “Manual update required” with a link to the new version.

Your tabs, bookmarks and settings are kept from one version to the next.

Beta program: the Beta channel gets new features before everyone else, with the same profile and the same data formats; going back to Stable is done in the same place. If something goes wrong, Help, Report a problem opens the GitHub form prefilled with the version and the system (and nothing else).

Crashes and performance

Settings, Diagnostics. Crash reports (minidumps) stay on your device and are listed under “Recent crashes”; they are only sent if you turn on “Send crash reports” and the installed version has a report server. A report contains the memory state of the process that crashed, the version and the system: never your history, bookmarks or passwords. Self-hosted servers can receive them (CRASH_REPORTS=1 on the sync relay).

Profiles, backup and crashes

  • Recovery after a crash: the session (windows, spaces, tabs, folders, split view) is saved continuously. If Browser closed badly, the start page offers “Restore the session?”: restore everything, choose windows or ignore. Settings, Behavior, “At startup”: continue where you left off or the start page.
  • Recently closed: “…” menu, History; “Reopen closed window” with Ctrl+Alt+Shift+T.
  • Crashed page: a tab whose process stops shows “This page crashed” with “Reload”; the rest of the browser carries on.
  • Task manager (Shift+Esc, browser://tasks): memory and CPU of each tab, extension and service, sortable; “End process” stops a greedy tab.
  • Print (Ctrl+P): preview with pages, orientation, margins, scale, backgrounds, then “Save as PDF” or a printer.
  • Profiles (browser://profiles): each profile has its settings, history, bookmarks, passwords, sessions and its sync. “Open” opens a window of that profile; “Choose the profile at startup” shows the list at launch.
  • Backup: “Export the profile…” writes a .browserbackup file (passwords only if you tick it, encrypted with a passphrase; never cookies). “Import a backup…” shows its content, then merges or replaces.

Encrypted sync

Bookmarks (and the favorites grid), the last 90 days of history, open tabs, spaces, theme, search engine, start page and boosts sync between your computers and your phone. Everything is encrypted on the device (XChaCha20-Poly1305) before sending: the server only sees unreadable data. Private windows and passwords are never synced (passwords only if you turn it on).

1. Deploy your server

No server is provided: sync stays off until you have one. The repository's server/ folder contains a small dependency-free relay (Node 22, Docker) and guides for a VPS with Caddy, Fly.io or Render: see server/README.md. Choose a REGISTRATION_SECRET, otherwise anyone could create an account on your server.

2. First device

  1. Settings (Ctrl ,), Sync, First device.
  2. Paste the server address (https://sync.example.com) and the registration code, then “Turn on sync”. The encryption key is created on this device.

3. Pair the others

  1. On the first device: “Show the pairing code”. This code gives access to all your synced data: don't share it.
  2. On the phone: Settings, Sync, “Scan the pairing code” (or paste the text code).
  3. On another computer: Join an existing account and paste the code.

Sync happens at startup, a few seconds after each change, every 5 minutes, and on the phone each time it comes back to the foreground (or “Sync now”). Your other devices' tabs appear in the universal bar and in the phone's tab view.

Send a tab to a device

Right-click in the page, “Send to a device”, then choose the paired device. The address travels end-to-end encrypted and expires after 7 days if it isn't received. The receiving computer opens it in the background with a notification; the phone asks “Open” or “Later” and keeps it under “Other devices”. Never from a private window.

  • Disconnect this device: stops sync here, the local data stays.
  • Reset (lost code, stolen device): erases the account on the server and creates a new one with a new key; pair your devices again.

To try it locally: cd server && npm ci && npm run build && npm start, then the address http://<PC-IP>:8787 (http is only accepted on the local network).

Troubleshooting and questions

Windows shows “Windows protected your PC”.
That's SmartScreen, which warns about an unsigned or rarely downloaded program. As long as the packages aren't signed: “More info”, then “Run anyway”. Check the file with SHA256SUMS.txt if you wish. Signing (Azure Trusted Signing) is ready and will be turned on in an upcoming version; even signed, a new executable can be flagged for a few days while it builds its reputation.
Netflix, Disney+, Prime Video or Spotify refuse to play.
They require the Widevine protected content module. Check Settings, Privacy, “Protected content (DRM)”: the switch must be on and a Widevine version shown. On the very first launch, the module downloads in a few seconds; restart the browser if it says “installing”. On Linux, Widevine isn't available. Some services keep high definition for browsers whose platform is verified (VMP signature of published versions).
Signing in to a Google account opens another browser.
Google refuses sign-ins from embedded browsers, so accounts.google.com pages open in your usual browser, where the sign-in works normally. Other sign-ins (Okta, Microsoft…) stay in Browser. If a Google site is still blocked, update Browser and report it on GitHub with the version: Google's checks evolve.
A site doesn't find my passkey or security key.
On Windows, sign-in goes through Windows Hello: check that it is set up. On macOS and Linux, only USB security keys without a PIN work; Touch ID, the iCloud keychain and sign-in with a phone aren't available. See “Addresses, cards and passkeys”.
I don't get notifications from a closed site.
Normal: background “push” notifications aren't supported. Keep the tab open (it can be in the background), and check that “Do not disturb” is off.
macOS says the app can't be opened.
Right-click Browser in Applications, “Open”; or System Settings, Privacy & Security, “Open Anyway”.
The AppImage doesn't start on Linux.
Make it executable (chmod +x). On some recent distributions, also install libfuse2.
In development, npm run dev doesn't find Electron.
Electron 44 no longer downloads its binary at install: scripts/ensure-electron.mjs does it on postinstall and before npm run dev. Run npm install again (or node scripts/ensure-electron.mjs), checking network access or the proxy.
npm install fails on a dependency conflict.
The repository's .npmrc turns on legacy-peer-deps; run the command at the repository root. On Windows, avoid a folder synced by OneDrive.
What does Anthropic see when I use the assistant?
Only what you ask it to read, when you ask: the title, address and text of the page (or the selection, or the compared tabs) and your question, sent directly by the browser with your key, never form fields or passwords. A warning reminds you of it before the first send, and in every private window. Nothing goes through our servers: the key is encrypted by the system on the device, never synced; conversations are neither written to disk nor synced. Anthropic's use of the data follows its API terms.
A site doesn't work properly.
Turn off the protections for that site (address bar's shield), then reload. If the site refuses https, the HTTPS-only page offers to continue.
A tab reloads when I come back to it.
It was asleep to free memory. Lengthen the delay or choose “Never” in Settings, Behavior.
A tab has disappeared.
It may have been archived: “Archived tabs” command or the universal bar's filter.
Sync doesn't start.
Check the address (https required outside the local network), the registration code, and that the server answers. The status and last error show in Settings, Sync.
Passwords aren't offered for saving.
Never in a private window; on Linux, a system keychain (GNOME Keyring, KWallet) is needed, otherwise nothing is saved.
Where is my profile?
In the app's data folder (%APPDATA%\Browser, ~/Library/Application Support/Browser or ~/.config/Browser). It is kept when uninstalling.
